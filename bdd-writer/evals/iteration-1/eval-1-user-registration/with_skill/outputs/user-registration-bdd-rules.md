# 用户注册功能 BDD 规则文档

## 需求摘要

| 维度 | 规则 |
|-----|------|
| 功能目标 | 用户通过填写用户名、密码、邮箱完成注册 |
| 数据范围-用户名 | 长度 3-20 字符，仅允许字母、数字、下划线 |
| 数据范围-密码 | 长度 8-32 字符，必须包含字母和数字 |
| 数据范围-邮箱 | 符合邮箱格式规范，最大 100 字符 |
| 唯一性约束 | 用户名和邮箱均不可重复 |
| 外部依赖 | 注册成功后发送验证邮件 |

---

## 业务规则

### BR-1: 用户名验证

- 用户名长度必须在 3-20 个字符之间
- 仅允许字母（a-z, A-Z）、数字（0-9）、下划线（_）
- 用户名必须唯一，不可与已注册用户重复
- 边界条件：空用户名、过短、过长、非法字符

### BR-2: 密码验证

- 密码长度必须在 8-32 个字符之间
- 必须包含至少一个字母和一个数字
- 边界条件：空密码、过短、过长、纯字母、纯数字

### BR-3: 邮箱验证

- 邮箱格式必须符合标准邮箱格式（user@domain.com）
- 邮箱最大长度 100 字符
- 邮箱必须唯一，不可与已注册用户重复
- 边界条件：空邮箱、格式错误、已存在邮箱

### BR-4: 注册流程

- 所有必填字段（用户名、密码、邮箱）必须填写
- 验证通过后创建用户记录
- 注册成功后发送验证邮件到用户邮箱
- 返回注册成功状态
