# 订单状态 BDD 规则文档

## 业务规则

### BR-1: 订单状态枚举

- 订单状态包括：`pending_payment`（待支付）、`paid`（已支付）、`shipped`（已发货）、`completed`（已完成）、`cancelled`（已取消）
- 状态值必须为上述枚举之一，其他值视为非法

### BR-2: 订单初始状态

- 新建订单的初始状态必须为 `pending_payment`（待支付）
- 订单创建时不能指定其他状态

### BR-3: 状态转换规则 - 支付

- 当前状态为 `pending_payment` 时，支付成功后转换为 `paid`
- 只有待支付状态的订单可以执行支付操作
- 其他状态执行支付操作应返回错误

### BR-4: 状态转换规则 - 发货

- 当前状态为 `paid` 时，可以发货转换为 `shipped`
- 只有已支付状态的订单可以执行发货操作
- 其他状态执行发货操作应返回错误

### BR-5: 状态转换规则 - 完成确认

- 当前状态为 `shipped` 时，确认收货后转换为 `completed`
- 只有已发货状态的订单可以执行完成确认
- 其他状态执行完成确认应返回错误

### BR-6: 状态转换规则 - 取消

- 当前状态为 `pending_payment` 时，可以取消订单转换为 `cancelled`
- 只有待支付状态的订单可以直接取消
- 已支付及之后状态的订单不能直接取消（需走退款流程，不在本范围）

### BR-7: 终态不可变

- `completed`（已完成）和 `cancelled`（已取消）为终态
- 终态订单不能再执行任何状态变更操作

### BR-8: 状态查询

- 支持按状态筛选订单列表
- 支持查询单个订单的当前状态

## 状态机图

```
                    ┌─────────────────┐
                    │ pending_payment │ ← 创建订单
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
              ▼              │              ▼
        ┌──────────┐         │        ┌───────────┐
        │   paid   │         │        │ cancelled │ (终态)
        └────┬─────┘         │        └───────────┘
             │               │
             ▼               │
       ┌──────────┐          │
       │ shipped  │          │
       └────┬─────┘          │
            │                │
            ▼                │
      ┌───────────┐          │
      │ completed │ (终态)   │
      └───────────┘          │
```

## 测试场景

| ID | 场景描述 | 输入条件 | 预期结果 |
|----|---------|---------|---------|
| S1 | 新建订单初始状态 | 创建订单 | 状态为 `pending_payment` |
| S2 | 待支付订单支付成功 | 状态 `pending_payment`，执行支付 | 状态变为 `paid` |
| S3 | 待支付订单取消 | 状态 `pending_payment`，执行取消 | 状态变为 `cancelled` |
| S4 | 已支付订单发货 | 状态 `paid`，执行发货 | 状态变为 `shipped` |
| S5 | 已发货订单确认收货 | 状态 `shipped`，执行确认 | 状态变为 `completed` |
| S6 | 已支付订单尝试取消 | 状态 `paid`，执行取消 | 操作失败，状态保持 `paid` |
| S7 | 已发货订单尝试支付 | 状态 `shipped`，执行支付 | 操作失败，状态保持 `shipped` |
| S8 | 已完成订单尝试任何操作 | 状态 `completed`，执行任意操作 | 操作失败，状态保持 `completed` |
| S9 | 已取消订单尝试任何操作 | 状态 `cancelled`，执行任意操作 | 操作失败，状态保持 `cancelled` |
| S10 | 非法状态值创建订单 | 状态 `invalid_status` | 创建失败 |
| S11 | 按状态筛选订单 | 筛选条件 `paid` | 返回所有已支付订单 |
| S12 | 查询订单当前状态 | 订单ID | 返回正确状态 |

## 边界条件

| 边界类型 | 测试点 |
|---------|--------|
| 状态转换边界 | 每个状态尝试所有可能的操作 |
| 非法状态 | 空值、null、未定义值 |
| 终态校验 | completed/cancelled 尝试所有转换 |
