# 购物车结算价格计算 - BDD 规则文档

## 需求摘要

| 维度 | 规则 |
|------|------|
| 业务目标 | 计算购物车最终结算金额，支持商品汇总、会员折扣、满减优惠、优惠券抵扣 |
| 数据范围 | 单价：0.01 ~ 999,999.99；数量：1 ~ 999；商品种类：1 ~ 100 |
| 角色差异 | 普通会员无折扣，VIP会员享受额外95折，SVIP享受9折 |
| 折扣规则 | 会员折扣与满减可叠加，优惠券与会员折扣不可叠加（取最优） |
| 满减规则 | 满100减10，满200减25，满500减80 |
| 优惠券 | 支持定额券（如10元、20元）、百分比券（如9折券） |
| 状态依赖 | 已下架商品不参与计算，库存不足时需提示 |
| 精度要求 | 金额保留2位小数，采用四舍五入 |

---

## 业务规则

### BR-1: 商品金额计算

- 商品小计 = 单价 × 数量
- 单价范围：0.01 ~ 999,999.99
- 数量范围：1 ~ 999
- 单价和数量必须为正数，否则返回错误

### BR-2: 购物车总金额计算

- 购物车总金额 = 所有商品小计之和
- 空购物车返回金额为 0
- 最多支持 100 种商品

### BR-3: 会员折扣

- 普通会员：无折扣（折扣率 1.0）
- VIP会员：95折（折扣率 0.95）
- SVIP会员：9折（折扣率 0.9）
- 会员折扣应用于商品总金额

### BR-4: 满减优惠

| 门槛金额 | 减免金额 |
|---------|---------|
| >= 100 | 减 10 |
| >= 200 | 减 25 |
| >= 500 | 减 80 |

- 满减以商品总金额为基准计算
- 满减可与其他折扣叠加

### BR-5: 优惠券抵扣

- 定额券：直接抵扣固定金额（如 10 元券、20 元券）
- 百分比券：按比例抵扣（如 9 折券 = 抵扣 10%）
- 优惠券与会员折扣不可叠加，取优惠金额较大者
- 优惠券金额不能超过应付金额

### BR-6: 结算金额计算顺序

1. 计算商品总金额
2. 应用满减优惠
3. 比较会员折扣与优惠券，取最优
4. 计算最终应付金额（最低为 0）

### BR-7: 边界与异常处理

- 商品单价 <= 0：返回错误
- 商品数量 <= 0：返回错误
- 商品单价超过最大值：返回错误
- 商品数量超过最大值：返回错误
- 最终金额为负数时，设为 0
- 精度处理：四舍五入保留 2 位小数
